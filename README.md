# my-blog

마크다운 파일을 읽어서 브라우저에서 바로 렌더링하는, 빌드 과정 없는 정적 블로그입니다.

## 로컬에서 실행하기

`index.html`을 더블클릭해서 `file://`로 직접 열면 마크다운 파일을 불러오지 못합니다 (브라우저가 로컬 파일에 대한 `fetch` 요청을 CORS로 차단하기 때문). 반드시 간단한 정적 서버로 열어주세요.

```bash
python -m http.server 8000
```

또는 VS Code의 Live Server 확장을 사용해도 됩니다. 서버를 띄운 뒤 `http://localhost:8000` 으로 접속하세요.

## 새 글 추가하기

1. `posts/` 폴더에 `내-글-제목.md` 형태로 마크다운 파일을 추가합니다.
2. `posts/manifest.json`에 아래 형식으로 항목을 하나 추가합니다.

```json
{
  "slug": "내-글-제목",
  "title": "화면에 보일 제목",
  "date": "2026-01-01",
  "excerpt": "목록에 보일 짧은 요약",
  "tags": ["태그"]
}
```

`slug`는 파일명(확장자 제외)과 반드시 일치해야 합니다. 저장하고 새로고침하면 홈 화면 목록과 상세 페이지에 바로 반영됩니다.
